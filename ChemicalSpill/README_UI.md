# Интерфейс оператора — устройство проекта

Дизайн выполнен фасадом: разметка ничего не знает об источнике данных, а ядро
подключается реализацией интерфейсов из папки `Services`.

## Папки

| Папка | Назначение |
|---|---|
| `View/` | Весь дизайн: окно-оболочка, экраны разделов, элементы, модальные окна, оформление |
| `View/Themes/` | Палитра, стили элементов управления, сопоставление моделей представления с разметкой |
| `View/Controls/` | Блок стадии мнемосхемы, плитка параметра, график |
| `View/Pages/` | Экраны разделов |
| `View/Dialogs/` | Модальные окна: выбор рецепта, подключение к установке |
| `View/Converters/` | Преобразователи значений для привязок |
| `View/Services/` | `DialogService` — единственное место, где модель представления касается окон |
| `ViewModels/` | Модели представления: свойства для привязки и команды-заглушки |
| `Models/` | Перечисления и структуры данных из документов |
| `Services/` | Интерфейсы сервисов — точка подключения ядра |
| `Services/Demo/` | Демонстрационные реализации, чтобы фасад запускался без ядра |

## Как подключить ядро

Единственное место сборки — `App.xaml.cs`, метод `OnStartup`. Достаточно заменить
объекты `Demo*` своими реализациями:

```csharp
IMachineService machine = new MachineService(...);   // вместо DemoMachineService
IRecipeService recipes = new RecipeService(...);     // вместо DemoRecipeService
// и так далее
```

Разметку и модели представления править при этом не требуется.

## Контракты

| Интерфейс | Что закрывает |
|---|---|
| `IMachineService` | Состояние установки, мнемосхема, параметры, разрешающие условия, пуск и останов |
| `ISettingsService` | Настройки цикла, проверка диапазонов, расчёт времени такта |
| `IRecipeService` | Рецепты: версионность, состояния, проверки при сохранении и загрузке |
| `INetworkService` | Связь по Ethernet, процедура подключения двумя ключами |
| `IJournalService` | Журнал и отчёты о партиях |
| `ITrendService` | Кривые параметров во времени |
| `IVideoService` | Видеонаблюдение рабочей камеры |
| `IDialogService` | Модальные окна (реализован в `View/Services`) |

## Соответствие документам

* «Функциональный интерфейс управления установкой» — мнемосхема (раздел 2),
  настройки цикла и расчёт такта (раздел 3), органы управления (раздел 4),
  рецепты (раздел 5).
* «Перечень параметров, выводимых оператору» — плитки главного экрана, таблица
  и графики раздела «Параметры и графики», типы величин И / У / А / Р.
* «Подключение установки к персональному компьютеру» — раздел «Сеть и
  подключение», признак связи в строке состояния, мастер подключения.

## Просмотр без ядра

Приложение запускается на демонстрационных данных: в боковом меню внизу выводится
отметка «Демонстрационные данные».

* «Сервис → Имитация аварии» — показывает блокирующую панель аварии;
* «Сервис → Имитация блокировки пуска» — показывает перечень невыполненных
  разрешающих условий и недоступную кнопку «Пуск».

Выгрузка файлов работает: данные графиков и журнал сохраняются в CSV
(разделитель «точка с запятой», кодировка UTF-8 — открывается в Excel без
настройки), отчёт о партии — в текстовый файл, рецепт — в файл с контрольной
суммой, пригодный для обратной загрузки.
