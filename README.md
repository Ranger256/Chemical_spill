# ChemicalSpill

Программное обеспечение для персонального компьютера под управлением ОС Windows,
предназначенное для управления станком.

Установка автоматизированного дозирования и упаковки жидких особо чистых веществ
в условиях контролируемой атмосферы. Компьютер является вторым местом управления:
с него доступны наблюдение за ходом цикла, настройка параметров, работа с
рецептами, просмотр журналов и органы управления пуском и остановом.

## Состав

На текущем этапе реализован пользовательский интерфейс (фасад):

* главный экран — мнемосхема технологического цикла, основные параметры,
  органы управления, аварии, консоль событий, изображение с камеры;
* параметры и графики — перечень выводимых величин и кривые во времени;
* настройки цикла — параметры по стадиям и расчёт времени такта;
* рецепты — состав, версионность и проверки;
* журнал и отчёты;
* сеть и подключение к установке;
* видеонаблюдение рабочей камеры.

Ядро и контроллер подключаются реализацией интерфейсов из папки `Services`.
Подробнее — [ChemicalSpill/README_UI.md](ChemicalSpill/README_UI.md).

## Требования

* ОС Windows;
* .NET Framework 4.8.1;
* Visual Studio 2019 или новее (для сборки).

## Сборка и запуск

```
git clone <адрес репозитория>
```

Открыть `ChemicalSpill.sln` в Visual Studio и выполнить сборку конфигурации
`Debug` или `Release`. Готовый файл — `ChemicalSpill\bin\<конфигурация>\ChemicalSpill.exe`.

Сборка из командной строки:

```
msbuild ChemicalSpill.sln /p:Configuration=Release
```

## Состояние работ

Интерфейс работает на демонстрационных данных: в боковом меню выводится отметка
«Демонстрационные данные». Связь с установкой и логика цикла будут реализованы
отдельно.
